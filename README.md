# Fantastic Food

A student-facing Year 7 Technology Mandatory course for the Fantastic Food unit.

The site includes five guided learning modules, practical recipes, a student folio, assessment information, video learning, activities and teacher resources. Student responses are saved only in the browser on the current device and are not submitted to Google Classroom.

The teacher program is aligned to the NSW Technology 7–8 (2023) syllabus for mandatory implementation from 2026.
